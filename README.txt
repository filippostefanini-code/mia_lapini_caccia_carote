MIA & I LAPINI — CACCIA ALLE CAROTE
====================================

Gioco web per Mia, utilizzabile da telefono, tablet o computer.

COME SI GIOCA
- Premi "Gioca".
- Muovi Mia con il dito/touch oppure con le frecce della tastiera.
- Avvicinati a una carota per raccoglierla automaticamente.
- Portala nel cestino prima che un Lapino la raggiunga.
- Dopo 3 carote, Mia vince lo smoothie carota-arancia-limone a bordo piscina.

AVVIO
1. Apri index.html con un browser moderno.
2. Non serve installare nulla e non serve Internet.

FILE
- index.html      schermata e struttura dell'app
- style.css       grafica e adattamento a telefono/tablet
- game.js         logica del gioco
- assets/mia_manga.png  immagine di Mia in stile manga usata nel gioco

Nota: se il browser limita l'apertura di file locali, avvia un piccolo server locale
nella cartella (ad esempio `python -m http.server 8000`) e apri http://localhost:8000.
